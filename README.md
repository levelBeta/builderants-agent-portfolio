# builderAnts Agent Portfolio

A portfolio of local, offline reference AI agents built by builderAnts.

Each agent follows the same design principles: deterministic detection, an LLM that only explains, a tamper-evident audit log, a process-scoped sovereignty check, and a regression eval.

All data in this repository is synthetic.
